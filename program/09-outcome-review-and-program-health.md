# Measure the program itself (avoid the dead-dashboard cycle)

**A program that produces attractive charts but no decisions is not succeeding.**

## Proposed program performance measures
| Measure | What it reveals | Caveat |
|---|---|---|
| % published executive findings with named decision owner | Whether issues have actionable authority | More decisions does not mean better security |
| % validated Reporting Unit challenges resolved within a service target | Fairness and credibility | Targets require agreement |
| % published metrics passing coverage/freshness gates | Measurement trustworthiness | Exclude inapplicable cases transparently |
| Time from confirmed material trend to decision | Decision-process friction | Urgent issues have separate path |
| % actions with scheduled and completed outcome review | Follow-through discipline | Completion alone does not imply success |
| % measures retired or revised when no longer useful | Portfolio hygiene | Changes require history/version control |
| Recurring manual reporting effort | Whether the program reduces one-offs | Count hours using a consistent baseline |
| Changes in outcome measures after action | Whether intervention helped | Consider other causes and changing populations |

## Review rhythm
- Weekly operational data-health review: staleness, ingestion, identity joins, unresolved challenges.
- Monthly program+Reporting Unit interpretation: validate persistent issues and decisions.
- Quarterly enterprise decision-and-outcome meeting: policies, shared capabilities, investment options.
- Annual measurement portfolio review: retire metrics with no decision use; validate organizational profiles.

## Decision ledger states
**Candidate → Evidence reviewed → Reporting Unit impact validated → Decision requested → Authorized/monitor → Implementing → Outcome review → Closed / reopened**.

The program can return a finding to investigation rather than artificially pushing everything upward.

## Three reasons to **not** escalate
1. Short-lived count change with documented remediation and no material unresolved consequence.
2. Unreliable denominator or unknown coverage: open a measurement-quality action instead.
3. Reporting Unit-owned issue that has an authorized owner and remedy without enterprise intervention.

## One exception
Immediate threats follow incident/emergency response criteria, irrespective of the normal trend review.
